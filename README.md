# 3×3 큐브 가이드

큐브의 여섯 면 색을 입력하면 해법을 계산하고, 각 회전을 3D 애니메이션과 단계별 안내로 보여주는 데스크톱 앱입니다. GUI는 PySide6, 해법 계산은 `kociemba` 패키지를 사용합니다.

## 실행 환경

- Windows 10/11
- Python 3 및 `pip` (Windows 실행 파일은 Python 3.13을 우선 사용하고, 없으면 Python Launcher의 기본 버전을 사용합니다.)
- `requirements.txt`에 적힌 Python 패키지

## 실행

처음 한 번 필요한 패키지를 설치합니다.

```powershell
py -3.13 -m pip install -r requirements.txt
```

Python 3.13이 없다면 설치한 Python 버전에 맞춰 실행합니다.

```powershell
py -m pip install -r requirements.txt
```

Python Launcher가 없다면 `python -m pip install -r requirements.txt`를 사용합니다. 이후 `run.bat`을 더블 클릭하거나 프로젝트 폴더에서 실행합니다.

```powershell
.\run.bat
```

직접 실행하려면 다음 명령을 사용할 수 있습니다.

```powershell
python gui_3d.py
```

## 사용 방법

1. **색상 입력** 화면에서 실제 큐브의 앞면(F)과 윗면(U)을 기준으로 정합니다. 각 면은 바깥에서 정면으로 바라본 방향으로 입력합니다.
2. 색상 팔레트를 선택한 뒤 스티커를 클릭해 입력합니다. 스티커에서 마우스 오른쪽 버튼을 누른 채 색상 방향으로 드래그해 입력할 수도 있습니다. 지우개를 선택하면 클릭한 색을 지웁니다.
3. 중앙 색 배치가 기본 예시와 다를 때만 **중앙 색 수정**을 켜고 중앙 스티커를 수정합니다. 중앙 수정이 꺼져 있으면 중앙 스티커의 우클릭 색상 선택기는 열리지 않습니다.
4. 색상별 개수와 미입력 칸을 확인하고 **해법 찾기**를 누릅니다. 색을 입력할 때 현재 정보만으로 확실하게 결정되는 칸은 자동 입력됩니다.
5. **회전 안내**에서 3D 큐브를 확인하고 실제 큐브를 안내에 따라 돌립니다. 전개도 보기, 애니메이션 속도, 기준 시점을 사용할 수 있습니다. 마우스 드래그로 수평(Y)축 회전과 위아래 시점 이동을 할 수 있으며, 위아래 이동은 수직 방향에서 0.5° 안쪽(약 90°)까지로 제한됩니다. 오른쪽의 다음 기준점은 다음 회전 면의 중앙 색과 위쪽 면의 색을 컬러 블록으로 표시합니다. `돌렸어요 · 다음`을 누르거나 회전 안내 화면에서 스페이스바를 눌러 다음 단계로 이동합니다.

입력이 잘못되었거나 새로 시작하려면 색상 입력 화면의 **색상 초기화**를 누릅니다.

## 프로젝트 구성

- `gui_3d.py` — 3D 애니메이션 GUI의 실행 진입점 및 단계 안내 화면
- `gui.py` — 색상 입력, 전개도, 해법 계산, 회전 단계 및 공통 GUI 구성요소
- `cube3d.py` — Qt 페인터 기반 3D 큐브 렌더링, 카메라 이동 및 회전 애니메이션
- `cube_engine.py` — 큐브 색 입력 검증, 면 회전 시뮬레이션 및 `kociemba` 연동
- `requirements.txt` — Python 의존성 목록
- `run.bat` — Windows 실행 및 의존성 확인 스크립트

`gui.py`를 직접 실행하면 2D 안내 버전을 사용할 수 있습니다.
